# 03 首页与编辑器体验优化 — 技术设计

> Phase: 1（博客核心）  
> Status: 已完成

## 前端设计

### 首页与导航

- `Header` 的导航锚点增加 `#home`，并将文章区域继续映射到 `#articles`。
- 默认首页锚点从文章区调整为首屏，确保首次访问时“首页”处于激活状态。
- 品牌头像、Hero 背景光晕、社交按钮和滚动按钮采用局部 CSS 类实现，避免在 JSX 中堆叠复杂视觉声明。
- Hero 使用 `100svh` 计算首屏高度，扣除固定导航高度，改善移动浏览器地址栏变化时的布局表现。
- 社交入口当前使用不可点击元素和“待配置”提示，避免产生无效外链。

### 文章请求状态

- `PostListPage` 不再在组件顶层提前返回加载或错误组件。
- 页面外壳、Hero 和侧栏始终渲染，加载与错误反馈仅替换精选文章区域。
- 最新文章入口复用现有 `featuredPost` 数据，不增加额外请求。

### 编辑表单数据回填

- 使用 `loadedSlug` 记录哪篇文章已经写入本地表单，替代容易受 effect 执行顺序影响的布尔 ref。
- 只有当 `currentPost.slug` 与路由 `slug` 一致时才初始化表单，避免旧请求数据写入新页面。
- 从编辑模式返回新建模式时恢复 `initialState`。
- Milkdown 只在目标文章数据已经就绪后挂载，并通过路由 slug 设置 `key`，切换文章时创建干净的编辑器实例。

### Milkdown 生命周期与样式

- 使用 ref 固定编辑器首次挂载时的 `initialContent`，内容变化通过 `markdownUpdated` 回传表单，不因 React 重渲染重复创建 Crepe。
- 同时引入 Crepe 通用样式和 classic 主题，避免只有主题变量而缺少基础组件样式。
- 开启 Crepe `TopBar`、关闭悬浮 `Toolbar`，让常用格式操作具有稳定位置。
- `MilkdownEditor.css` 只作用于 `.blog-editor` 命名空间，设置颜色变量、顶栏尺寸、正文留白和移动端适配，避免污染文章渲染样式。

## 后端设计

本次改动不涉及后端，也不改变现有 API 契约。

## 数据与接口

- 不新增数据库字段或迁移。
- 不新增网络请求。
- 继续使用现有文章列表和文章详情接口。

## 风险与边界

- GitHub、邮箱和 RSS 仅为视觉占位，配置真实链接时需要替换为可访问的锚点并补充安全属性。
- Milkdown 相关构建产物较大，本次保证按编辑页拆分，但暂不进一步拆分编辑器内部依赖。
- 作者操作入口从公共导航移除后，仍可直接访问 `/editor`；真正的权限隔离需要后续认证功能完成。
